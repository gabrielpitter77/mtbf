# MTBF · Troca e Ressarcimento · LOC Frotas

Painel: https://gabrielpitter77.github.io/mtbf/

- `index.html`: a página do painel.
- `base.json`: as tabelas de MTBF (aberto, sem criptografia).

## Atualização (administrador)

1. Atualize a planilha **Base Única de MTBF** (uma aba por cliente + "Demais Clientes (Padrão)" + "Índice").
2. No painel: **Carregar base** (senha de administrador) → escolha a planilha → confira o resumo.
3. Clique em **Gerar base.json para publicar**.
4. Neste repositório: **Add file → Upload files**, arraste o `base.json` (substitui o antigo) → **Commit changes**.
5. Em até ~10 minutos todos veem a base nova.
